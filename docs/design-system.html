05

Usage

Rules that keep the interface honest and coherent as it grows.

✓Do
  • Keep work surfaces strictly neutral — desaturated grays only, so photos read true.
  • Set every numeric readout in IBM Plex Mono; digits must align in fixed-width columns.
  • Reserve the accent for the single active/primary action in any given view.
  • Fill bipolar sliders from center; unipolar from the left edge.
  • Use the pill segmented control for mutually-exclusive modes (Library / Develop).
✕Don't
  • Don't introduce warm or saturated surfaces around the image — they bias color perception.
  • Don't use more than one accent-filled button per view; extras compete for attention.
  • Don't set numbers in the sans UI face; it breaks column alignment and rhythm.
  • Don't add new hues. Status is teal / red / amber only — nothing else.
  • Don't round containers past 8px or drop shadows on flat panels.
